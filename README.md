# battery-soh-bench

Открытый студенческий контест по оценке SOH литий-ионных ячеек. Участникам
выдаются готовые parquet-файлы: размеченные `train` и `val` и безразметочный
`test`. Скачивать и подготавливать исходные датасеты для участия не нужно.

## Задача и данные

По фрагменту зарядной кривой предскажите долю сохранившейся ёмкости `soh_pred`
для каждого `fragment_id`. Подробности задачи, данных, формата CSV и метрик
описаны в [документации контеста](docs/README.md).

Публичные parquet находятся в `data/fragments/`:

- `train.parquet` — обучающие фрагменты с колонкой `soh`;
- `val.parquet` — validation с колонкой `soh`;
- `test_unlabeled.parquet` — тестовые фрагменты без меток.

## Отправка

Положите `submission.csv`, описание подхода и исходный код обучения в
`submissions/<team-slug>/` и откройте pull request. CI проверит CSV, вычислит
оценку и обновит результат команды в PR и лидерборде. Код из PR для вычисления
официального результата не запускается.

При желании установите инструменты проверки: нужен [uv](https://docs.astral.sh/uv/).
После клонирования репозитория выполните `uv sync`, затем проверьте файл так:

```bash
uv run bsb validate --submission submissions/<team-slug>/submission.csv
```

Полный pipeline загрузки и подготовки исходных датасетов хранится в закрытом
репозитории организаторов. В этом публичном репозитории остаются данные для
участников, правила контеста, CSV-validator и доверенный PR scorer.
