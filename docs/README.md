## Самое короткое изложение задачи

По окну зарядной кривой шириной 0.2 В и длиной 128 точек (заряд, ток,
температура) нужно предсказать `soh_pred`. Основная оценка — MAE в процентных
пунктах SOH; LFP оценивается отдельно. Номер цикла и история ячейки участникам
не передаются.

Начните с [задачи и данных](02-задача-и-данные.md), затем изучите
[формат сабмита](03-сабмит-и-метрики.md). Для проверки CSV можно установить
проект командой `uv sync` и запустить `uv run bsb validate --submission FILE`.
