## Самое короткое изложение задачи

Есть кусок зарядной кривой ячейки — окно шириной 0.2 В, 128 точек, три канала
(заряд, ток, температура). Нужно по нему сказать, насколько ячейка изношена:
одно число `soh_pred` от 0 до 1. Оценка — средняя абсолютная ошибка в
процентных пунктах SOH.

Обучение и тест — разные наборы данных: учиться предлагается на CALCE, Oxford и
Sandia R&D, а проверяться — на Sandia SNL (NCA, NMC и отдельно LFP). Номер
цикла и история ячейки на вход не подаются: решение должно работать по одному
фрагменту.

uv sync                       # окружение одной командой
uv run bsb config-check       # проверка, что всё встало
